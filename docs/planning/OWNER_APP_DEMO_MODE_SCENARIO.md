# 점주 앱 데모 자동 진행 모드

Last updated: 2026-05-11

## 목적

발표 녹화에서 사람이 직접 느리게 클릭하는 장면을 줄이고, 점주 앱의 핵심 업무 흐름이 실제 시연처럼 빠르게 지나가도록 만든다.

로그인과 데모 모드 진입은 실제 앱에서 직접 수행한다. 그 이후 자동 데모 화면은 실제 운영 화면과 분리된 발표용 화면이며, API 호출 없이 동작하므로 만료 토큰이나 DB 상태 때문에 `401 Unauthorized` 로그가 반복되지 않는다.

## 진입 방법

| 위치 | 조작 |
|---|---|
| 로그인 첫 화면 | 필요 시 테스트용으로 상단 로고/제목 영역을 850ms 안에 3번 빠르게 탭 |
| 로그인 후 홈 화면 | 발표 녹화 권장. `안녕하세요, 청주 햇살농원 점주님` 인사말/점주 이름 영역을 850ms 안에 3번 빠르게 탭 |

진입 후 `점주앱 자동 데모` 화면으로 이동한다.

## 데모 모드 동작 규칙

| 항목 | 값 |
|---|---|
| 자동 진행 딜레이 | 단계당 약 1.65초 |
| 강조 방식 | 펄스 원, 진한 글자색, 강조 배경, 강조 테두리 |
| 일시정지 | 우측 상단 pause 버튼 |
| 수동 이동 | 하단 `이전`, `다음` 버튼 |
| 종료 | 좌측 상단 X 버튼 |

## 색상 강조 규칙

| 상황 | 강조 색 | 사용 위치 |
|---|---|---|
| 기본 탭/상품/배송 | 진한 녹색 `#215C42` | 메뉴 글자, CTA 버튼, 펄스 원 |
| 예측/신선도 분석 | 파란색 `#2364AA` | 예측값, 분석 결과, 보조 판정 |
| 발주 승인 | 갈색-노랑 `#9B6A00` | 선택된 발주, 승인 버튼 |
| 반품 승인 | 적갈색 `#B64033` | 반품 요청, 승인 처리 |

## 자동 시연 순서

| 구간 | 수행 방식 | 실제 사용자가 누르는 위치 | 데모 강조 |
|---:|---|---|---|
| A | 실제 조작 | 이메일 입력, 비밀번호 입력, `로그인` 버튼 | 앱 실제 로그인 화면 |
| B | 실제 조작 | 홈 상단 `안녕하세요, 청주 햇살농원 점주님` 영역 3회 빠른 탭 | 데모 모드 진입 |
| 1 | 자동 데모 | 하단 `메뉴` 탭 | 하단 메뉴 위치에 펄스 원, 업무 현황 카드 강조 |
| 2 | 자동 데모 | `기본 관리` 섹션의 `상품 관리` 카드 | `상품 관리` 글자 진한 녹색, 카드 테두리 강조 |
| 3 | 자동 데모 | 우측 상단 `+` 버튼, 등록 완료 | 양광/부사 상품 행과 등록 완료 CTA 강조 |
| 4 | 자동 데모 | `수확 예측 실행`, 이후 `수확 슬롯 열기` | 예상 수확량, 권장 예약량, 슬롯 오픈 수량 강조 |
| 5 | 자동 데모 | 첫 번째 발주 체크박스, `승인` 버튼 | 선택된 발주와 승인 버튼 강조 |
| 6 | 자동 데모 | 이미지 박스, `분석`, `저장` | 이미지 선택, 추천 등급 A, 점주 판정 PASS 강조 |
| 7 | 자동 데모 | 발주 선택, QR/스캔 버튼, `등록` | 택배사, 송장번호, 배송 등록 완료 강조 |
| 8 | 자동 데모 | 반품 요청 카드, `승인` 버튼 | 고객 첨부 이미지, 승인 금액, 현황 갱신 강조 |

## 발표 문구

```text
예측 결과와 신선도 판정은 자동 결정이 아니라 점주의 판단을 돕는 보조 정보입니다.
고객에게 노출되는 수확 슬롯과 출고 여부는 점주가 최종 확정합니다.
```

## 녹화 권장 흐름

1. 앱 실행
2. 컴퓨터 유즈 또는 사람이 실제 로그인 입력
3. 홈 화면 진입 확인
4. 홈 화면 상단 `안녕하세요, 청주 햇살농원 점주님` 영역을 3번 빠르게 탭
5. 데모 모드 진입 확인
6. 자동 재생 상태로 8단계가 한 바퀴 돌 때까지 녹화
7. 필요하면 pause 후 `이전`/`다음`으로 특정 장면만 다시 촬영

## 주의 사항

- 이 모드는 발표용 시각화이며 실제 DB 저장을 수행하지 않는다.
- 운영 화면의 실제 기능은 기존 메뉴에서 그대로 검증한다.
- 발표 녹화에서는 일반 화면을 수동으로 오래 누르지 말고 이 데모 모드를 사용한다.
