# 점주 앱 시연 모드 시나리오

작성일: 2026-05-11
최종 갱신: 2026-05-12

## 진입 방식

- 일반 사용자는 보이지 않는다.
- 점주 계정 로그인 후 홈 화면 상단의 점주 인사 문구를 3번 빠르게 탭하면 기존 자동 시연 모드가 시작된다.
- 홈 화면 서브타이틀인 농장명을 3번 빠르게 탭하면 `tutorial_coach_mark` 기반 설명형 튜토리얼 모드가 시작된다.
- 진입 이후 별도 데모 화면으로 이동하지 않고, 실제 앱 페이지 위에만 하이라이트 오버레이를 띄운다.
- 화면 하단에 단계 설명 문구나 진행도 박스를 띄우지 않는다.
- 하이라이트는 실제 누를 수 있는 메뉴, 버튼, 이미지 선택 영역, 입력 컨트롤을 기준으로 표시한다.
- 전체 화면 딤은 사용하지 않는다.
- 화면 이동, 탭 전환, 자동 스크롤 중에는 하이라이트를 즉시 숨긴다.
- 대상 위치가 2프레임 이상 안정된 뒤 좌표를 한 번 측정하고, 그 고정 좌표에만 얇은 반투명 선을 표시한다.
- 하이라이트는 대상 위젯을 실시간 추적하지 않는다. 따라서 이동 중 박스가 따라오거나 좌상단에서 나타나면 결함으로 본다.
- 하이라이트 애니메이션, 전체 딤, 큰 펄스 점, 하단 설명 박스, 진행도 표시는 사용하지 않는다.
- 기본 지연 시간은 화면 전환 약 1.1초, 자동 스크롤 약 0.45초, 대상 강조 약 4초로 둔다.
- 설명형 튜토리얼 모드는 스킵 버튼을 숨기고, 각 타겟의 핵심 설명을 버블로 표시한다. 화면 또는 타겟을 탭하면 다음 단계로 넘어간다.

## 자동 진행 순서

발표 자료의 큰 흐름은 `스마트 계획 -> 데이터 동기화 -> 품질 · 물류 관리 -> 배송/사후 관리`이다.
앱 데모는 메뉴 소개가 아니라 점주가 실제 업무 화면에서 오늘 처리할 일을 확인하고, 각 메뉴 안에서 등록/예측/검사/처리 직전까지 조작하는 흐름으로 진행한다.

### 1. 홈 대시보드 업무 현황 확인

1. 홈 진입
   - 강조 대상: 상단 점주 인사 문구
   - 설명: 점주 계정과 농장명을 확인하고 오늘 업무 현황으로 시작한다.

2. 선별 대기 확인
   - 강조 대상: `업무 현황 > 선별 대기`
   - 이동: 실제 `신선도 검사` 페이지
   - 설명: 품질 검사 대기 건이 어떤 화면으로 이어지는지 먼저 보여준 뒤 홈으로 돌아온다.

3. 신규 발주 확인
   - 강조 대상: `업무 현황 > 신규 발주`
   - 이동: 실제 `발주 승인` 페이지
   - 설명: 고객 주문 이후 점주가 승인해야 하는 발주 목록을 확인하고 홈으로 돌아온다.

4. 배송 준비 확인
   - 강조 대상: `업무 현황 > 배송 준비`
   - 이동: 실제 `배송 관리` 페이지
   - 설명: 출고 가능한 발주 상품이 배송 등록 화면으로 이어지는지 확인하고 홈으로 돌아온다.

5. 반품 요청 확인
   - 강조 대상: `업무 현황 > 반품 요청`
   - 이동: 실제 `반품 · 환불 관리` 페이지
   - 설명: 배송 후 사후 처리 요청이 어디에서 접수되는지 확인하고 홈으로 돌아온다.

6. 메뉴 탭 이동
   - 강조 대상: 하단 `메뉴` 탭
   - 설명: 대시보드 현황을 확인한 뒤 전체 기능 메뉴로 이동한다.

### 2. 메뉴별 실제 기능 시연

7. 상품 관리 메뉴
   - 강조 대상: `상품 관리` 메뉴
   - 이동: 실제 `상품 관리` 페이지

8. 상품 등록 시작
   - 강조 대상: 우측 상단 `+` 상품 등록 버튼
   - 이동: 실제 `상품 추가` 페이지
   - 설명: 실제 저장은 하지 않고 등록 직전까지의 입력 과정을 보여준다.

9. 상품 등록 폼 확인
   - 강조 대상: `사과 품종`, `포장 단위`, 대표 이미지, `기본 판매가`, `등록` 버튼
   - 데모 상태: `양광`, `5kg 박스`, 등록용 양광 이미지, 41,000원 값이 프리셋으로 들어간다.
   - 실제 동작: OS 사진 피커 자동 조작 대신 demo asset을 선택된 상태로 만든다.

10. 수확 예측 메뉴
   - 강조 대상: `수확 예측` 메뉴
   - 이동: 실제 `수확 예측` 페이지

11. 수확 예측 입력 확인
   - 강조 대상: 상품 선택, 최근 기준 수확량, 예측 반영 기준 카드
   - 설명: 점주 입력값, 상품 등록값, 날씨/작황 기준이 점주용 문구로 표시된다.

12. ML 예측 실행
   - 강조 대상: `수확 예측 실행` 버튼
   - 실제 동작: `HarvestSlotPage(demoAutoPredict: true)`가 실제 예측 API를 호출하고, 실패하면 앱 보조 예측으로 폴백한다.

13. ML 예측 결과 확인
   - 강조 대상: 결과 차트, 권장 예약량/판매가, `1,000㎡ 기준 수확량`, 신뢰도 카드
   - 설명: 차트에는 kg 수치를 표시하고, API의 `confidence`, `warning_message`, `unit_yield_kg_10a`는 점주용 표현으로 번역해 보여준다.

14. 수확 슬롯 확정 직전
   - 강조 대상: `수확 슬롯 열기` 버튼
   - 설명: 예측값을 바탕으로 수확 기간, 예약 가능 수량, 판매가를 점주가 최종 확정하는 지점을 보여준다.

15. 주문 현황 메뉴
   - 강조 대상: `주문 현황` 메뉴
   - 이동: 실제 `주문 현황` 페이지

16. 고객 예약/결제 결과 확인
   - 강조 대상: `주문` 탭, `결제 완료` 주문 카드, `예약` 탭, `예약 유지` 카드, `주문 전환` 카드
   - 설명: 고객 앱을 열지 않고도 점주 앱에서 고객 예약 생성, 결제 완료, 주문 전환 결과가 DB에 들어온 상태를 확인한다.

17. 발주 승인 메뉴
   - 강조 대상: `발주 승인` 메뉴
   - 이동: 실제 `발주 승인` 페이지

18. 발주 승인 상세 처리
   - 강조 대상: 첫 발주 카드, `전체 승인`, 첫 품목 승인 수량, `결정 저장` 버튼
   - 실제 동작: `ProcurementPage(demoOpenFirst: true)`가 첫 발주를 보여준 뒤 상세로 자동 진입한다.
   - 설명: 목록만 보는 것이 아니라 고객 주문으로 생성된 발주를 품목별 승인 수량까지 확인한다.

19. 발주 현황 메뉴
   - 강조 대상: `발주 현황` 메뉴
   - 이동: 실제 `발주 현황` 페이지
   - 강조 대상: 첫 발주 현황 카드
   - 설명: 제목만 훑지 않고 승인 저장 후 상태 추적 항목이 실제로 쌓이는 화면을 보여준다.

20. 신선도 검사 메뉴
   - 강조 대상: `신선도 검사` 메뉴
   - 이동: 실제 `신선도 검사` 페이지

21. 신선도 검사 대상/이미지 확인
   - 강조 대상: 검사 대상 드롭다운, 이미지 선택 박스
   - 데모 상태: 검사 대상 품종에 맞는 사과 이미지가 이미 선택된 상태로 표시된다.

22. DL 분석 실행과 결과 확인
   - 강조 대상: `분석` 버튼, 추천 등급, 신선도, 색상 점수, 형태 점수, 멍 확률, 모델 판정
   - 실제 동작: `DL_QUALITY_API_URL`이 있으면 ngrok DL 서버에 multipart 이미지 요청을 보내고, 실패하면 백엔드 분석/앱 보조 판정으로 폴백한다.

23. 점주 최종 판정 저장 직전
   - 강조 대상: `점주 확정 등급`, `점주 판정`, `저장` 버튼
   - 설명: 모델 결과는 보조 자료이고 최종 출고 판단은 점주가 확정한다.

24. 배송 관리 메뉴
   - 강조 대상: `배송 관리` 메뉴
   - 이동: 실제 `배송 관리` 페이지

25. 배송 등록 흐름
   - 강조 대상: 스캔 버튼, 발주 승인 상품 드롭다운, 송장번호 입력 필드, `등록` 버튼
   - 실제 동작: `ShipmentPage(demoAutofill: true)`가 첫 배송 가능 발주를 선택하고 송장번호/박스/중량을 자동 입력한다.

26. 배송 현황 메뉴
   - 강조 대상: `배송 현황` 메뉴
   - 이동: 실제 `배송 현황` 페이지
   - 강조 대상: 첫 배송 현황 카드
   - 설명: 배송 등록 후 송장과 발송 상태가 표시되는 실제 항목을 확인한다.

27. 반품 · 환불 관리 메뉴
   - 강조 대상: `반품 · 환불 관리` 메뉴
   - 이동: 실제 `반품 · 환불 관리` 페이지

28. 반품 상세 처리
   - 강조 대상: 첫 반품 요청 카드, 고객 첨부 이미지, 승인 금액, `승인` 버튼

## 하이라이트 표시 규칙

- `_focus()`는 항상 먼저 현재 하이라이트를 숨긴다.
- 대상 `GlobalKey.currentContext`가 생길 때까지 짧게 대기한다.
- `Scrollable.ensureVisible()`로 실제 대상이 보이는 위치까지 이동한다.
- 이동 후 `RenderBox.localToGlobal()` 좌표가 안정될 때까지 기다린다.
- 안정된 `Rect`를 오버레이에 넘겨 고정 좌표로만 표시한다.
- 다음 대상, 화면 이동, 루트 복귀, 새 페이지 push 시 하이라이트는 다시 숨긴다.
- 대상당 표시 시간은 4초다.

## 발표 검수 체크리스트

- 데모가 별도 fake page로 이동하지 않고 실제 점주 앱 화면 위에서 진행되는가.
- 메뉴만 훑지 않고 상품 등록, 예측 실행, 주문/예약 확인, 발주 상세, 신선도 분석, 배송 입력, 반품 상세가 이어지는가.
- 이동/스크롤 중 하이라이트가 완전히 사라지는가.
- 하이라이트가 좌상단에 잠깐 뜨거나 이동 대상을 따라오지 않는가.
- 하단 설명 박스, 진행도 표시, 전체 딤 레이어, 큰 펄스 점이 없는가.
- OS 사진 피커 자동 조작 없이 프리셋 이미지가 안정적으로 표시되는가.
- 고객 앱은 열지 않되, 점주 앱 `주문 현황`에서 고객 예약/결제 결과를 확인할 수 있는가.
