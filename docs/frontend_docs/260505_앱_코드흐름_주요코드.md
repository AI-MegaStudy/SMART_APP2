# 260505 앱 코드 흐름 및 주요 코드

## 목적

이 문서는 현재 `lib` 폴더 기준으로 Harvest Slot 점주앱의 코드 흐름, 주요 파일 역할, 재사용 코드 패턴을 정리한다. 앱은 Flutter Material 3 기반이며, 로그인 후 점주 운영 업무를 `메뉴 / 홈 / 내 정보` 하단 탭으로 탐색하는 구조다.

## 폴더 구조

```text
lib/
  main.dart
  core/
    api_service.dart
  model/
    dashboard_model.dart
  repositories/
    dashboard_repository.dart
  util/
    app_colors.dart
  view/
    *_page.dart
    home.dart
  vm/
    dashboard_viewmodel.dart
  widgets/
    owner_widgets.dart
```

## 앱 시작 흐름

1. `main.dart`의 `main()`에서 `OwnerApp`을 실행한다.
2. `OwnerApp`은 `MultiProvider`로 `DashboardViewModel`을 등록한다.
3. `MaterialApp`의 `home`은 `LoginPage`다.
4. 로그인 버튼을 누르면 `LoginPage -> Home`으로 이동한다.
5. `Home`은 하단 탭 쉘이며 `메뉴 / 홈 / 내 정보` 세 페이지를 전환한다.

```text
main()
  -> OwnerApp
  -> MultiProvider
  -> MaterialApp
  -> LoginPage
  -> Home
  -> MenuPage / DashboardPage / ProfilePage
```

## Provider 및 데이터 흐름

대시보드 데이터는 `View -> ViewModel -> Repository -> ApiService -> Model` 흐름을 따른다.

```text
DashboardPage
  -> DashboardViewModel.loadDashboard()
  -> DashboardRepository.fetchDashboard()
  -> ApiService.get('/owner/dashboard')
  -> DashboardModel.fromJson()
```

`DashboardRepository`는 API 호출 실패 시 `DashboardModel.demo()`를 반환한다. 그래서 API 연동이 불안정해도 홈 대시보드 UI는 demo 데이터로 표시된다.

## 화면 이동 규칙

### 로그인

`LoginPage`는 로그인 버튼 클릭 시 `Navigator.pushReplacement`로 `Home`을 연다. 로그인 후 뒤로 가기로 로그인 화면에 돌아가지 않도록 한 구조다.

### 하단 탭

`Home`은 `selectedIndex`로 현재 탭을 관리한다. 기본 선택값은 `1`이라 로그인 직후 홈 대시보드가 보인다.

```text
0: MenuPage
1: DashboardPage
2: ProfilePage
```

### 상세 페이지

`MenuPage`의 각 메뉴 카드는 `Navigator.push`로 상세 페이지를 연다. 홈 대시보드의 지표 카드도 해당 상세 페이지로 직접 이동한다.

## 입력 및 검증 패턴

폼 화면은 `GlobalKey<FormState>`와 `TextEditingController`를 사용한다. 저장 버튼에서는 먼저 `formKey.currentState?.validate()`를 실행하고, 통과하면 `showConfirmAction`으로 확인 얼럿을 띄운다.

```text
입력값 검증
  -> 실패: SnackBar 안내
  -> 성공: 확인 얼럿
  -> 확인: 상태 갱신 SnackBar 또는 화면 이동
```

전화번호, 사업자번호, 송장 번호는 `DashTextInputFormatter`로 숫자만 입력해도 하이픈이 자동 삽입된다.

## 상태 변경 확인 얼럿

저장, 승인, 등록, 로그아웃처럼 상태를 바꾸는 액션은 `showConfirmAction`을 사용한다. 얼럿 하단 버튼은 `취소 / 확인`을 한 줄에 배치하고 각 버튼이 너비의 절반을 차지한다.

## 디자인 시스템 연결

색상은 `AppColors`를 우선 사용한다.

```text
green: 주 브랜드 컬러
mint: 선택/보조 배경
line: 테두리
yellow: 주의/대기 상태
blue: 정보 상태
text: 기본 텍스트
muted: 보조 텍스트
```

`main.dart`의 `ThemeData`는 Material 3, 입력창, FilledButton, NavigationBar 스타일을 전역으로 관리한다.

## 개발 시 참고 규칙

- 새 화면은 `lib/view/*_page.dart`로 추가한다.
- 하단 탭 쉘은 `lib/view/home.dart`에 유지한다.
- 반복 UI는 `owner_widgets.dart`에 공통화한다.
- 색상은 `AppColors`에 추가 후 사용한다.
- 상태가 필요한 화면은 `StatefulWidget`과 controller를 사용한다.
- API 데이터가 필요한 기능은 `model -> repository -> vm -> view` 흐름을 따른다.
- 상태 변경 액션은 바로 실행하지 않고 `showConfirmAction`을 거친다.
