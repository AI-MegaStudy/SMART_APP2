# 260508 작업 내역

## 개요

2026년 5월 8일 진행한 점주 관리 앱 수정 내역이다. 이번 작업은 상품 수정 페이지 분리, 입력 폼 UX 정리, 상품/발주/배송/반품 화면의 표시 규칙 및 상태 흐름 보강을 중심으로 진행했다.

## 상품 수정 페이지 분리

- 상품 추가 페이지와 상품 수정 페이지를 분리했다.
- `product_add_page.dart`는 상품 등록만 담당하도록 정리했다.
- `product_edit_page.dart`를 새로 생성했다.
- 상품 관리 페이지에서 상품 카드를 누르면 `ProductEditPage`로 이동한다.
- 상품 수정 완료 시 수정된 상품 데이터가 상품 관리 목록에 반영된다.

## 공통 입력 폼

- 입력 폼의 힌트 텍스트를 각 라벨 텍스트 기준으로 통일했다.
- 정규식 검증이 적용된 폼은 포커스 시 간단한 입력 규칙을 helper text로 보여주도록 변경했다.
- 숫자 입력 폼은 숫자 키보드와 숫자 전용 입력 제한을 유지했다.
- `kg`, `kg 박스`, `원` 같은 고정 단위는 입력값이 없어도 항상 보이도록 변경했다.
- 드롭다운 메뉴에 `선택하세요.` 기본 항목을 추가했다.
- 수정 페이지 외 입력 폼은 기본 입력값을 비운 상태로 정리했다.

## 내 정보 및 농장 정보

- 내 정보 수정 페이지의 `배송 알림` 기본값을 `즉시 알림`으로 변경했다.
- 내 정보 수정 페이지 입력 폼 기본값을 비웠다.
- 농장 정보 수정 페이지의 `소개` 라벨을 `농장 소개`로 변경했다.
- 농장 정보 수정 페이지 입력 폼 기본값을 비웠다.
- 농장 정보의 지역 드롭다운도 `선택하세요.` 기본값을 사용하도록 정리했다.

## 상품 관리

- 상품 카테고리를 `양광 사과`, `부사 사과` 2개만 사용하도록 변경했다.
- 상품 추가/수정 페이지의 상품명은 직접 입력 대신 드롭다운 선택으로 변경했다.
- 상품 추가/수정 페이지에 `상품 수량` 입력 폼을 추가했다.
  - 숫자만 입력 가능하다.
  - `kg` 단위를 고정 표시한다.
- 상품 카드 하단 정보를 `가격 · 잔여 --kg` 형식으로 통일했다.
- 상품 재고가 20kg 미만이면 잔여 수량 텍스트를 빨간색으로 표시한다.
- 기존 `사고 재고 확인 필요` 문구는 제거했다.
- 각 상품 카드 우측에 `>` 아이콘을 추가했다.
- 상품 삭제 모드를 변경했다.
  - `삭제` 진입 후 같은 줄 좌측에 `전체 선택`, 우측에 `삭제` 버튼을 표시한다.
  - `완료` 버튼은 하단 우측에 별도로 표시한다.
  - 삭제 버튼은 확인 얼럿을 거친 뒤 선택 상품을 삭제한다.

## 수확 예측

- 차트 막대의 그라데이션을 제거하고 단색으로 변경했다.
- 하단 `임시 저장` 버튼을 제거했다.
- 예약 오픈 수량 입력 폼은 빈 값으로 시작한다.
- 예약 오픈 수량은 숫자만 입력 가능하고 `kg` 단위를 고정 표시한다.

## 예약 · 주문 현황

- 주문 상품명을 `양광`, `부사` 기준으로 정리했다.
- 상품 카드의 `날짜 수확분` 문구를 제거했다.
- 요청 시간만 표시하도록 서브 타이틀을 정리했다.
- `오늘` 문구를 제거했다.
- 오래된 요청 시간이 상단에 오도록 정렬했다.

## 발주 승인

- 발주 승인 카드의 `날짜 수확분` 문구를 제거했다.
- 결제된 시간을 표시하도록 변경했다.
- 먼저 결제한 건이 상단에 오도록 정렬했다.
- 거절 사유 드롭다운에 `선택하세요.` 기본값을 추가했다.
- 거절 얼럿의 `취소 / 거절` 버튼을 한 줄로 나열했다.
- 거절 사유를 선택하지 않으면 거절 버튼을 누를 수 없도록 했다.

## 발주 현황

- `승인 대기` 필터를 제거했다.
- 발주 현황 카드 타이틀을 `년-월-일 시:분` 형식으로 변경했다.
- 서브 타이틀은 `구매자 이름 · 구매 상품 · 금액 또는 거절 사유` 형식으로 정리했다.

## 배송 관리 및 배송 현황

- 배송 관리 페이지의 상품 드롭다운은 발주 승인 완료 상품만 노출하도록 변경했다.
- 송장번호 입력 폼은 빈 값으로 시작한다.
- 송장번호 정규식 안내 문구를 `1234-1234-1234` 형식으로 맞췄다.
- 배송 현황 카드 하단 정보에 날짜를 포함했다.
- 배송 현황 상품명을 `양광`, `부사` 기준으로 정리했다.

## 반품 · 환불 관리

- 반품 상세 페이지를 폼 구조로 변경했다.
- 반품 승인 시 모든 필수 입력값을 검증하도록 변경했다.
- `승인 금액`은 숫자 키보드와 숫자 전용 입력 제한을 적용했다.
- `승인 금액`에 `원` 단위를 고정 표시한다.
- 고객 첨부 사진은 첨부 개수만큼 표시한다.
- 첨부 사진이 없으면 이미지 영역을 표시하지 않는다.
- 반품 거절 사유 드롭다운에 `선택하세요.` 기본값을 추가했다.
- 거절 얼럿의 `취소 / 거절` 버튼을 한 줄로 나열했다.
- 거절 사유를 선택하지 않으면 거절 버튼을 누를 수 없도록 했다.
- 반품 요청 목록의 상태 문구를 `확인 필요` 대신 `접수`로 정리했다.

## 반품 · 환불 현황

- 반품 현황 필터에서 `확인 필요`를 제거했다.
- 반품 현황 카드 하단 정보에 날짜를 포함했다.
- 반품 현황 상품명을 `양광`, `부사` 기준으로 정리했다.
