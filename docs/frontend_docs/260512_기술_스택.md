# 260512 기술 스택

## 개요

현재 앱은 Flutter 모바일 프론트엔드와 FastAPI 백엔드를 REST API로 연결하는 구조다. 점주 앱의 화면은 Flutter Material 3로 구성되어 있고, 상태 관리는 화면 내부 `StatefulWidget`과 `Provider`를 함께 사용한다. 백엔드는 FastAPI, SQLAlchemy, MySQL, JWT 인증, 이미지 업로드, ML/DL 분석 연동을 담당한다.

## 프론트엔드

| 기술 | 사용 위치 | 목적 |
| --- | --- | --- |
| Flutter | `lib/main.dart`, `lib/view` | Android, iOS, Web, Desktop 대응 앱 UI |
| Dart | 전체 Flutter 코드 | 앱 로직과 UI 구현 언어 |
| Material 3 | `ThemeData(useMaterial3: true)` | 앱 전역 디자인 시스템 |
| Provider | `main.dart`, `dashboard_viewmodel.dart` | 대시보드 상태 관리 |
| StatefulWidget | 대부분의 `lib/view/*_page.dart` | 폼, 로딩, 선택 상태 관리 |
| shared_preferences | `core/auth_session.dart` | access token과 role 로컬 저장 |
| image_picker | 상품/농장/선별 검사 화면 | 갤러리 이미지 선택 |
| kpostal_plus | 회원가입/농장 상세 | 주소 검색 |
| tutorial_coach_mark | `lib/demo` | 점주 앱 코치 투어 |

## 백엔드

| 기술 | 사용 위치 | 목적 |
| --- | --- | --- |
| FastAPI | `backend/app/main.py` | REST API 서버 |
| Uvicorn | `backend/requirements.txt` | FastAPI 실행 서버 |
| SQLAlchemy | `backend/app/core/database.py`, `backend/app/models` | ORM과 DB 세션 관리 |
| PyMySQL | `backend/app/core/config.py` | MySQL 드라이버 |
| Pydantic Settings | `backend/app/core/config.py` | `.env` 기반 설정 관리 |
| python-jose | `backend/app/core/security.py` | JWT 토큰 처리 |
| passlib/bcrypt | 인증 서비스 | 비밀번호 해시 |
| python-multipart | 이미지 업로드 API | multipart/form-data 처리 |

## 핵심 흐름 요약

```text
사용자 액션
  -> Flutter View
  -> Repository
  -> ApiService
  -> FastAPI Router
  -> Service
  -> SQLAlchemy Repository
  -> MySQL
```

이미지 분석 흐름:

```text
이미지 선택
  -> Flutter image_picker
  -> 이미지 업로드 API
  -> 외부 DL 분석 API
  -> 실패 시 FastAPI 품질 분석
  -> 실패 시 로컬 추정값
  -> 선별 결과 저장
```

수확 예측 흐름:

```text
상품/농장/과거 수확량 선택
  -> 자동 기상 feature 요청
  -> scikit-learn 모델 예측
  -> 예약 가능 kg, 추천 가격, 예상 수확 기간
  -> 수확 슬롯 오픈
```
