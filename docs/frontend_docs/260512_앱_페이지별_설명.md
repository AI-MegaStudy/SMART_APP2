# 260512 앱 페이지별 설명

## 1. 앱 개요

이 앱은 과수 농장 점주가 상품, 수확 예약 슬롯, 주문, 발주 승인, 선별 검사, 배송, 반품을 관리하는 Flutter 기반 점주 앱이다. 로그인 후 하단 탭의 `메뉴 / 홈 / 마이` 구조로 진입하고, 각 업무 화면은 `lib/view` 아래의 페이지 파일로 구성된다.

## 2. 기본 화면 구조

| 영역 | 페이지 | 설명 |
| --- | --- | --- |
| 로그인 | `LoginPage` | 이메일/비밀번호로 점주 로그인 |
| 회원가입 | `SignupPage` | 이메일 인증 후 점주 계정 생성 |
| 계정 찾기 | `EmailFindPage`, `PasswordFindPage` | 이메일 찾기와 비밀번호 재설정 |
| 앱 셸 | `Home` | 하단 탭으로 메뉴, 홈, 마이 페이지 전환 |
| 홈 | `DashboardPage` | 처리해야 할 업무 현황 요약 |
| 메뉴 | `MenuPage` | 전체 업무 기능 진입 목록 |
| 마이 | `ProfilePage` | 점주 정보, 농장 정보, 로그아웃 진입 |

## 3. 페이지별 설명

### 3.1 `LoginPage`

앱의 첫 진입 화면이다. 이메일과 비밀번호를 입력하고 로그인하면 인증 API를 호출한 뒤, 성공 시 `Home`으로 이동한다. 회원가입, 이메일 찾기, 비밀번호 찾기 화면으로도 이동할 수 있다.

### 3.2 `SignupPage`

점주 회원가입 화면이다. 이메일 인증번호 발송/확인, 이름, 전화번호, 비밀번호, 주소 입력을 처리한다. 주소 검색은 `kpostal_plus`를 사용한다.

### 3.3 `EmailFindPage`

이름과 전화번호를 입력해 점주 계정 이메일을 찾는 화면이다. 결과는 마스킹된 이메일 또는 이메일 문자열로 표시된다.

### 3.4 `PasswordFindPage`

이름과 이메일로 비밀번호 재설정 코드를 요청하고, 인증 코드와 새 비밀번호를 입력해 비밀번호를 변경한다.

### 3.5 `Home`

로그인 후 보이는 앱의 하단 탭 컨테이너다. 기본 선택값은 홈 탭이므로 앱 진입 직후 `DashboardPage`가 먼저 열린다.

| 탭 | 페이지 | 역할 |
| --- | --- | --- |
| 메뉴 | `MenuPage` | 전체 업무 메뉴 |
| 홈 | `DashboardPage` | 업무 현황 대시보드 |
| 마이 | `ProfilePage` | 점주/농장 정보 관리 |

### 3.6 `DashboardPage`

점주가 지금 처리해야 할 업무를 카드 형태로 보여주는 홈 화면이다. 열린 수확 슬롯, 신규 발주, 선별 대기, 배송 준비, 반품 확인 같은 지표를 보여주고, 카드를 누르면 관련 업무 화면으로 이동한다.

| 카드 | 이동 화면 |
| --- | --- |
| 열린 수확 슬롯 | `HarvestSlotPage` |
| 신규 발주 | `ProcurementPage` |
| 선별 대기 | `QualityPage` |
| 배송 준비 | `ShipmentPage` |
| 반품 확인 | `ReturnPage` |

### 3.7 `MenuPage`

점주 앱의 전체 기능 목록이다. 업무를 `기본 관리`, `주문 처리`, `배송/반품` 섹션으로 나누고, 각 메뉴를 누르면 해당 상세 페이지로 이동한다.

| 섹션 | 메뉴 |
| --- | --- |
| 기본 관리 | 상품 관리, 수확 예측 및 슬롯 설정 |
| 주문 처리 | 예약/주문 현황, 발주 승인, 선별 검사 |
| 배송/반품 | 배송 관리, 배송 현황, 반품/환불 관리, 반품 현황 |

### 3.8 `ProfilePage`

점주 계정과 농장 정보를 관리하는 마이 페이지다. 점주 정보 수정, 농장 정보 수정, 로그아웃 기능을 제공한다.

### 3.9 `OwnerDetailPage`

점주 기본 정보를 수정하는 화면이다. 이름, 전화번호, 사업자번호, 발주/반품/배송 알림 설정을 관리한다.

### 3.10 `FarmDetailPage`

농장 정보를 수정하는 화면이다. 농장 이름, 지역, 주소, 소개, 배송 정책, 반품 정책, 농장 이미지를 관리한다. 주소 검색과 이미지 선택 기능이 포함된다.

### 3.11 `ProductPage`

점주가 등록한 상품 목록을 관리한다. 상품 상태별 필터링, 상품 추가, 상품 수정, 선택 상품 판매 중지를 제공한다.

### 3.12 `ProductAddPage`

새 상품을 등록하는 화면이다. 농장, 상품명, 과일 종류, 품종, 포장 단위, 기본 판매가, 판매 상태, 상품 설명, 상품 이미지를 입력한다.

### 3.13 `ProductEditPage`

기존 상품 정보를 수정하는 화면이다. `ProductAddPage`와 유사하지만 전달받은 상품 정보를 초기값으로 사용한다.

### 3.14 `HarvestSlotPage`

수확량 예측과 예약 슬롯 오픈을 담당하는 핵심 화면이다. 상품/농장을 선택하고 과거 수확량, 날씨, 생육 상태를 입력해 수확 예측을 요청한다. 예측 결과를 바탕으로 예약 가능 수량, 판매 가격, 수확 기간, 고객 안내문을 확정해 슬롯을 연다.

### 3.15 `OrdersPage`

예약과 주문 현황을 보여준다. 전체, 예약, 결제 완료, 배송 준비 등 상태별로 주문을 필터링해 확인할 수 있다.

### 3.16 `ProcurementPage`

고객 주문에 대한 발주 요청을 점주가 승인하거나 거절하는 화면이다. 요청 목록을 확인하고, 전체 승인/거절 또는 상세 수량 조정으로 처리한다.

### 3.17 `ProcurementDetailPage`

발주 품목별 승인 박스 수량, 승인 kg, 점주 메모를 조정하는 상세 승인 화면이다. 부분 승인 같은 세밀한 처리가 필요한 경우 사용한다.

### 3.18 `ProcurementStatusPage`

발주 처리 결과를 조회하는 화면이다. 승인, 부분 승인, 거절된 발주 기록을 확인한다.

### 3.19 `QualityPage`

선별 검사용 이미지를 선택하고, AI/DL 분석 결과를 확인한 뒤 점주가 최종 등급과 판정을 저장하는 화면이다. 이미지 선택, 분석, 결과 저장 흐름을 포함한다.

### 3.20 `ShipmentPage`

선별 검사가 완료된 발주 건을 배송 등록하는 화면이다. 택배사, 송장번호, 배송 박스 수, 배송 kg을 입력한다.

### 3.21 `ShipmentStatusPage`

배송 목록과 배송 상태를 관리한다. 배송 중, 배송 완료 등 상태 변경 액션을 제공한다.

### 3.22 `ReturnPage`

고객 반품/환불 요청을 점주가 승인하거나 거절하는 화면이다. 고객 첨부 이미지, 요청 사유, 승인 금액, 결정 사유를 확인하고 처리한다.

### 3.23 `ReturnStatusPage`

반품/환불 처리 현황을 조회하는 화면이다. API 데이터가 없을 때는 mock 데이터를 사용해 화면을 유지한다.

## 4. 공통 UI

대부분의 화면은 `lib/widgets/owner_widgets.dart`의 공통 컴포넌트를 사용한다.

| 컴포넌트 | 역할 |
| --- | --- |
| `AppScaffold` | SafeArea, 상단 제목, 스크롤 레이아웃 |
| `HeroPanel` | 상단 강조 패널 |
| `MetricCard` | 숫자 지표 카드 |
| `DataTile` | 목록 타일 |
| `StatusBadge` | 상태 라벨 |
| `FilterTabs` | 상태 필터 탭 |
| `DualActionBar` | 2개 버튼 액션 영역 |
| `PrimaryAction` | 주요 단일 액션 버튼 |
| `CameraPreviewCard` | 이미지 미리보기 |
