# 260512 앱 코드흐름 및 주요코드

## 1. 전체 코드 흐름

이 앱은 Flutter 화면에서 Repository를 호출하고, Repository가 `ApiService`를 통해 FastAPI 백엔드의 `/api/v1` REST API와 통신하는 구조다.

```text
Flutter View
  -> Repository
  -> ApiService
  -> FastAPI Router
  -> Service
  -> SQLAlchemy Repository
  -> MySQL
```

대시보드처럼 공유 상태가 필요한 화면은 `Provider`와 `ChangeNotifier`를 사용하고, 대부분의 상세 업무 화면은 `StatefulWidget` 내부에서 로딩, 입력값, 선택 상태를 관리한다.

## 2. 폴더별 역할

| 경로 | 역할 |
| --- | --- |
| `lib/main.dart` | 앱 시작점, 테마 설정, Provider 등록, 로그인 세션 복원 |
| `lib/core` | API 호출, 인증 세션, API 예외, 디버그 로그 |
| `lib/model` | API 응답과 화면 데이터를 담는 모델 |
| `lib/repositories` | 화면에서 필요한 데이터를 API 또는 fallback에서 가져오는 계층 |
| `lib/view` | 로그인, 대시보드, 메뉴, 업무 상세 페이지 |
| `lib/vm` | Provider 기반 화면 상태 관리 |
| `lib/widgets` | 점주 앱 공통 UI 컴포넌트 |
| `backend/app` | FastAPI 백엔드, 라우터, 서비스, DB 모델, 스키마 |

## 3. 앱 시작 흐름

앱은 `main.dart`의 `main()`에서 시작된다. `OwnerApp`은 앱 실행 시 `AuthSession.restore()`로 로컬 저장소의 로그인 세션을 복원한다.

```text
main()
  -> OwnerApp
  -> AuthSession.restore()
  -> MultiProvider
  -> MaterialApp
  -> 세션 있음: Home
  -> 세션 없음: LoginPage
```

주요 코드:

```dart
void main() {
  runApp(const OwnerApp());
}
```

```dart
late final Future<void> restoreSession = AuthSession.restore();

home: FutureBuilder<void>(
  future: restoreSession,
  builder: (context, snapshot) {
    if (snapshot.connectionState != ConnectionState.done) {
      return const Scaffold(
        body: Center(child: CircularProgressIndicator()),
      );
    }
    return AuthSession.isLoggedIn ? const Home() : const LoginPage();
  },
)
```

## 4. 로그인 및 세션 흐름

로그인 화면은 `AuthRepository.login()`으로 `/auth/login` API를 호출한다. 성공하면 access token과 role을 `AuthSession.login()`으로 `SharedPreferences`에 저장한다.

```text
LoginPage._login()
  -> AuthRepository.login()
  -> POST /auth/login
  -> AuthSession.login()
  -> Navigator.pushReplacement(Home)
```

세션 저장 코드:

```dart
static Future<void> login({
  required String token,
  required String userRole,
}) async {
  accessToken = token;
  role = userRole;
  final preferences = await SharedPreferences.getInstance();
  await preferences.setString(_accessTokenKey, token);
  await preferences.setString(_roleKey, userRole);
}
```

## 5. API 공통 호출 흐름

`ApiService`는 GET, POST, PUT, PATCH, multipart upload를 공통 처리한다. 인증이 필요한 요청에는 Bearer token을 붙인다.

```text
Repository method
  -> ApiService.getData/postData/putData/patchData
  -> _uri()
  -> _headers(requiresAuth)
  -> http 요청
  -> _decodeData()
  -> parser(data)
```

GET 요청 주요 코드:

```dart
static Future<T> getData<T>(
  String path, {
  T Function(Object? data)? parser,
  bool requiresAuth = false,
}) async {
  final response = await http
      .get(_uri(path), headers: _headers(requiresAuth: requiresAuth))
      .timeout(requestTimeout);

  return _decodeData(response, parser);
}
```

인증 헤더 주요 코드:

```dart
if (requiresAuth) {
  final token = AuthSession.accessToken;
  if (token == null || token.isEmpty) {
    throw const ApiException(message: '로그인이 필요합니다.');
  }
  headers['Authorization'] = 'Bearer $token';
}
```

## 6. 대시보드 데이터 흐름

대시보드는 Provider 기반으로 동작한다.

```text
DashboardPage
  -> DashboardViewModel.loadDashboard()
  -> DashboardRepository.fetchDashboard()

  -> DashboardModel.fromJson()
  -> notifyListeners()
```

Provider 등록:

```dart
MultiProvider(
  providers: [
    ChangeNotifierProvider(
      create: (_) => DashboardViewModel(DashboardRepository()),
    ),
  ],
  child: MaterialApp(...),
)
```

Repository 주요 코드:

```dart
final dashboard = await ApiService.getData<DashboardModel>(
  '/owner/dashboard',
  requiresAuth: true,
  parser: (data) {
    final json = data as Map<String, dynamic>? ?? const {};
    return DashboardModel.fromJson(json);
  },
);
```

## 12. 백엔드 연결 흐름

백엔드는 `backend/app/main.py`에서 FastAPI 앱을 만들고, `backend/app/routers/router.py`에서 기능별 라우터를 `/api/v1` 아래에 묶는다.

```text
backend/app/main.py
  -> FastAPI()
  -> CORS 설정
  -> 공통 exception handler
  -> api_router include

backend/app/routers/router.py
  -> auth_router
  -> product_router
  -> owner_router
  -> ml_router
  -> harvest_slot_router
  -> order_router
  -> procurement_router
  -> quality_router
  -> shipment_router
  -> return_router
```

DB 연결 주요 코드:

```python
engine = create_engine(
    settings.database_url,
    pool_pre_ping=True,
    future=True,
)
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine, future=True)
```

## 13. 개발 시 참고 규칙

- 새 화면은 `lib/view/*_page.dart`에 추가한다.
- API 호출은 화면에서 직접 하지 않고 `repositories`에 둔다.
- 인증이 필요한 API는 `requiresAuth: true`를 사용한다.
- API 응답 데이터는 `model`의 `fromJson()`으로 변환한다.
- 반복 UI는 `owner_widgets.dart`의 공통 컴포넌트를 먼저 재사용한다.
- 백엔드 데이터가 비어 있을 수 있는 화면은 fallback 데이터를 둘 수 있다.
