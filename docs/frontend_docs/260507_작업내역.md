# 260507 작업 내역

## 개요

2026년 5월 7일 진행한 점주 관리 앱 화면 및 기능 수정 내역이다. 이번 작업은 입력 검증, 검색, 화면 간 상태 갱신, 상품/발주/배송/반품 관리 흐름 보강을 중심으로 진행했다.

## 공통 UI 및 입력

- `AppScaffold`에 입력 폼 언포커싱 기능을 추가했다.
  - 빈 영역을 탭하면 키보드가 내려간다.
  - 스크롤 중에도 키보드가 닫히도록 처리했다.
- 전화번호, 사업자번호, 송장번호, 이름, 이메일, 비밀번호, 숫자 입력 검증 함수를 공통 위젯 파일에 정리했다.
- 숫자 입력 필드는 숫자 키보드와 숫자 전용 입력 제한을 적용했다.
- 상태 변경, 등록, 삭제 등 주요 액션은 확인 얼럿을 거치도록 맞췄다.

## 로그인 및 회원가입

- 로그인 페이지에 회원가입 버튼을 추가했다.
- `signup_page.dart`를 생성했다.
- 회원가입 입력 항목에 정규식 검증을 적용했다.
  - 이름
  - 이메일
  - 비밀번호
  - 전화번호
  - 사업자번호

## 상품 관리

- 상품 추가 페이지의 버튼 텍스트를 `저장`에서 `등록`으로 변경했다.
- 상품 등록 완료 시 상품 관리 페이지 목록에 새 상품이 추가되도록 연결했다.
- 상품 수정 흐름을 추가했다.
  - 상품 카드 선택 시 상품 수정 페이지로 이동한다.
  - 기존 상품 정보를 입력 폼에 채운다.
  - 수정 완료 시 상품 관리 목록이 갱신된다.
- 상품 관리 페이지에 검색 기능을 추가했다.
- 상품 카드의 상품명 옆에 포장 단위를 함께 표시하도록 변경했다.
- 하단에 `삭제` 텍스트 버튼을 추가했다.
  - `삭제` 선택 시 체크박스 삭제 모드로 전환된다.
  - 선택 후 `완료`를 누르면 확인 얼럿을 띄우고 선택 상품을 삭제한다.
- 상품 데이터 모델을 `lib/model/product_record.dart`로 분리했다.

## 상품 추가

- 포장 단위는 숫자만 입력하도록 변경했다.
- 포장 단위 뒤에 `kg 박스`를 고정 suffix로 표시했다.
- 기본 판매가는 숫자만 입력하도록 변경했다.
- 기본 판매가 뒤에 `원`을 고정 suffix로 표시했다.

## 수확 예측

- 예약 오픈 수량 입력 필드에 숫자 키보드와 숫자 전용 검증을 적용했다.
- `예약 오픈`은 모든 항목을 입력해야 가능하도록 변경했다.
- `임시 저장`은 모든 항목을 입력하지 않아도 통과하도록 분리했다.
- 차트 레이아웃 overflow 문제를 수정했다.

## 예약 · 주문 현황

- 검색 기능을 유지했다.
- 상태 필터에서 `배송 준비`를 제거했다.
- 주문 더미 데이터를 발주 승인 페이지에서도 참조할 수 있도록 공용 데이터로 정리했다.
