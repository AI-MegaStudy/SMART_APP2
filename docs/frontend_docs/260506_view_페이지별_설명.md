# 260505 lib/view 페이지별 설명

## 개요

`lib/view`는 앱의 화면 단위 파일을 담는다. 대부분의 화면은 `AppScaffold`를 기본 레이아웃으로 사용하고, 상세 화면은 `Scaffold(body: AppScaffold(...))` 형태로 작성되어 있다.

현재 하단 탭은 `메뉴 / 홈 / 내 정보`이며, 업무 상세 화면은 메뉴 또는 홈 카드에서 `Navigator.push`로 열린다.

## 페이지 목록

| 파일 | 클래스 | 역할 |
| --- | --- | --- |
| `login_page.dart` | `LoginPage` | 로그인 화면 |
| `home.dart` | `Home` | 하단 탭 쉘 |
| `dashboard_page.dart` | `DashboardPage` | 홈 대시보드 |
| `menu_page.dart` | `MenuPage` | 업무 메뉴 목록 |
| `profile_page.dart` | `ProfilePage` | 내 정보 메인 |
| `owner_detail_page.dart` | `OwnerDetailPage` | 내 정보 수정 |
| `farm_detail_page.dart` | `FarmDetailPage` | 농장 정보 수정 |
| `product_page.dart` | `ProductPage` | 상품 관리 |
| `product_add_page.dart` | `ProductAddPage` | 상품 추가 |
| `harvest_slot_page.dart` | `HarvestSlotPage` | 수확 예측 · 슬롯 확정 |
| `orders_page.dart` | `OrdersPage` | 예약 · 주문 현황 |
| `procurement_page.dart` | `ProcurementPage` | 발주 승인 |
| `quality_page.dart` | `QualityPage` | 신선도 검사 |

| `return_page.dart` | `ReturnPage` | 반품 · 환불 관리 |

## 1. `login_page.dart`

로그인 진입 화면이다. 이메일과 비밀번호 입력 필드를 보여주고, 로그인 버튼을 누르면 `Home`으로 이동한다.

주요 코드 흐름:

```text
LoginPage
  -> TextEditingController(email/password)
  -> FilledButton 로그인
  -> Navigator.pushReplacement(Home)
```

실제 인증 API는 아직 연결되어 있지 않고, demo 계정 기반 화면 전환만 담당한다.

## 2. `home.dart`

로그인 이후 앱의 메인 쉘이다. `NavigationBar`로 3개 탭을 전환한다.

탭 구성:

```text
메뉴: MenuPage
홈: DashboardPage
내 정보: ProfilePage
```

`selectedIndex`의 기본값은 `1`이라 앱 진입 후 홈 탭이 먼저 열린다. `DashboardPage`에는 `onJump` 콜백을 전달해 홈에서 특정 탭으로 이동할 수 있게 한다.

## 3. `dashboard_page.dart`

홈 대시보드 화면이다. `DashboardViewModel`을 통해 대시보드 지표를 읽고, 카드 UI로 주요 상태를 보여준다.

주요 구성:

- 상단 `HeroPanel`
- 열린 수확 슬롯
- 신규 발주
- 선별 대기
- 배송 준비
- 긴급 확인 카드

카드 클릭 동작:

```text
열린 수확 슬롯 -> HarvestSlotPage
신규 발주 -> ProcurementPage
선별 대기 -> QualityPage
배송 준비 -> ShipmentPage
반품 확인 -> ReturnPage
```

## 4. `menu_page.dart`

점주 업무 전체를 리스트로 제공하는 메뉴 화면이다. `MenuSection`, `MenuEntry`, `_MenuTile`로 메뉴 데이터를 화면에 뿌린다.

섹션:

- 기본 관리: 상품 관리, 수확 예측 · 슬롯 확정
- 주문 처리: 예약 · 주문 현황, 발주 승인, 신선도 검사
- 배송 · 반품: 배송 관리, 반품 · 환불 관리

각 항목은 `Navigator.push`로 상세 페이지를 연다.

## 5. `profile_page.dart`

내 정보 탭의 메인 화면이다. 상단 배너 아래에 `내 정보`, `농장 정보` 리스트를 보여준다.

동작:

- 내 정보 클릭 -> `OwnerDetailPage`
- 농장 정보 클릭 -> `FarmDetailPage`
- 로그아웃 클릭 -> 확인 얼럿 후 `LoginPage`로 이동

로그아웃은 `pushAndRemoveUntil`을 사용해 이전 화면 스택을 제거한다.

## 6. `owner_detail_page.dart`

점주 기본 정보를 수정하는 화면이다.

입력 항목:

- 이름
- 전화번호
- 사업자번호
- 발주 알림
- 반품 알림
- 배송 알림

전화번호와 사업자번호는 숫자만 입력해도 `DashTextInputFormatter`로 하이픈이 자동 삽입된다. 알림 설정은 `RadioGroup`과 `RadioListTile`로 구성되어 있다.

저장 흐름:

```text
Form validate
  -> 실패: SnackBar
  -> 성공: showConfirmAction
  -> 확인: 저장 완료 SnackBar
```

## 7. `farm_detail_page.dart`

농장 기본 정보를 수정하는 화면이다.

입력 항목:

- 농장명
- 지역
- 주소
- 소개
- 배송 정책
- 반품 정책

지역은 `LabeledDropdown`으로 도시 단위까지 선택한다. 주소는 `주소 검색` 버튼을 눌러 bottom sheet에서 검색 결과를 고르고, 선택한 주소를 입력 필드에 반영한다.

저장 전 모든 항목을 검증하고, 확인 얼럿에서 확인을 눌러야 저장 상태가 갱신된다.

## 8. `product_page.dart`

상품 관리 화면이다. 상품 상태 분류 탭과 상품 리스트를 제공한다.

분류 탭:

- 전체
- 판매 중
- 준비 중
- 중지

`FilterTabs`의 선택값에 따라 노출 상품을 필터링한다. 상단 플러스 버튼을 누르면 `ProductAddPage`로 이동한다.

## 9. `product_add_page.dart`

새 상품을 추가하는 화면이다.

입력 항목:

- 상품명
- 포장 단위
- 기본 판매가
- 판매 상태

저장 버튼은 form 검증 후 확인 얼럿을 띄우고, 확인 시 상품 추가 완료 메시지를 출력한 뒤 이전 화면으로 돌아간다.

## 10. `harvest_slot_page.dart`

수확 예측과 예약 슬롯 확정을 다루는 화면이다.

주요 구성:

- 예측 안내 `NoticeBox`
- 수확량 차트 `YieldChart`
- 예상 수확 범위/예상 수확량/권장 예약량/권장 판매가 지표
- 예약 오픈 수량
- 고객 안내 문구

하단 액션:

- 임시 저장
- 예약 오픈

두 액션 모두 확인 얼럿을 거친 뒤 상태 메시지를 출력한다.

## 11. `orders_page.dart`

예약 및 주문 현황 화면이다. 주문 상태에 따라 리스트를 필터링한다.

분류 탭:

- 전체
- 예약
- 결제 완료
- 배송 준비

`FilterTabs` 선택값에 맞는 주문 카드만 표시한다.

## 12. `procurement_page.dart`

발주 승인 화면이다. 발주 상태 필터, 승인 박스 수, 승인 중량을 선택할 수 있다.

분류 탭:

- 전체
- 승인 대기
- 승인 완료
- 거절

입력/선택:

- 승인 박스 수: 1박스부터 10박스
- 승인 중량: 1kg부터 20kg

부분 승인 또는 승인 버튼을 누르면 확인 얼럿을 띄우고, 확인 시 상태 메시지를 출력한다.

## 13. `quality_page.dart`

신선도 검사 화면이다. 상단 이미지 버튼을 눌러 갤러리 bottom sheet를 열고, 이미지를 선택하면 상단 `CameraPreviewCard`에 선택 결과가 반영된다.

주요 구성:

- 이미지 컨테이너
- 판별 안내 문구
- 추천 등급
- 신선도 점수
- 판정 결과 카드

현재 갤러리는 실제 기기 갤러리 연동이 아니라 demo 선택 UI다.

## 14. `shipment_page.dart`

배송 관리 화면이다. 배송에 필요한 택배사, 송장 번호, 박스 수, 중량을 입력/선택한다.

입력/선택:

- 택배사: 드롭다운
- 송장 번호: 숫자 입력 시 하이픈 자동 삽입
- 발송 박스 수: 1박스부터 10박스
- 발송 중량: 1kg부터 20kg

배송 등록 버튼은 확인 얼럿을 거쳐 상태 메시지를 출력한다.

## 15. `return_page.dart`

반품 및 환불 관리 화면이다. 고객이 구매한 상품 금액과 요청 사유를 점주가 확인하는 용도이므로 입력 필드는 disabled 상태다.

표시 항목:

- 구매 상품 금액
- 고객 요청 사유
- 결정
- 승인 금액
- 결정 사유

하단 액션:

- 거절
- 환불 승인

두 액션 모두 확인 얼럿을 거친 뒤 상태 메시지를 출력한다.

## 페이지 작성 패턴

새 페이지를 추가할 때는 아래 패턴을 우선 따른다.

```text
Scaffold
  -> AppScaffold
    -> leading: back button
    -> trailing: optional action
    -> children: page content
```

폼 화면은 다음 패턴을 사용한다.

```text
StatefulWidget
  -> GlobalKey<FormState>
  -> TextEditingController
  -> LabeledField / LabeledBox / LabeledDropdown
  -> DualActionBar or PrimaryAction
  -> validate
  -> showConfirmAction
```
